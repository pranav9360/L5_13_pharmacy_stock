# Lab 5 findings

All line numbers below refer to the original 83-line `pharmacy_system.py`
at starter commit `55a462f`, before any edits. Tool IDs and locations were
transcribed from the actual files in `reports/before/`. Manual bugs were
identified by inspecting that source and, where shown, running the original
program. A tool finding and a related logical bug are distinguished explicitly.

| Issue | Type | Line(s) | Description | Fix Approach |
|-------|------|---------|-------------|--------------|
| SQL injection | Tool: Bandit B608, medium severity, low confidence; manually reproduced | 21-22 | SQL interpolates the patient name. The baseline input `' OR 1=1 --` returns all three patients. Pylint C0209 also reports the formatting expression, but replacing it with an f-string would leave the vulnerability. | Bind the name with SQLite's `?` parameter and a one-element tuple; test malicious input and names containing apostrophes. |
| Dispensing beyond available stock | Manual: correctness | 29-39, 73 | Dispensing 30 Amoxicillin units when only 20 exist succeeds and leaves -10 units in the baseline output. | Check availability before mutation; reject insufficient stock without changing either stock or prescription history. |
| Allergy bypass and substring matching | Manual: correctness | 32, 70-75 | Mixed case lets Kavya receive Penicillin despite her recorded penicillin allergy. Substring matching can also block a different medicine merely because its name is part of an allergy name. | Normalize medicine and comma-separated allergy names with strip/casefold and compare exact names. Test both recorded allergies, mixed case, multiple allergies, and substring false positives. |
| Invalid quantities | Manual: correctness | 24-25, 35, 72 | Negative stock is accepted; zero, negative, fractional, string, and boolean dispensing quantities are unchecked. Negative dispensing can increase stock. | Require positive integer additions/dispensing, explicitly exclude booleans, and allow nonnegative integer quantities when loading existing inventory. Test rejection without state changes. |
| Expired medicine and wrong expiry window | Manual: correctness | 35, 41-47 | Dispensing ignores expiry. Negative date differences include already expired medicine in the upcoming window; datetime rounding and `< days` mishandle boundaries. The baseline lists the already expired Amoxicillin. | Compare calendar dates, reject dispensing after expiry, and include only in-stock medicines with `0 <= days_remaining <= days`. Test expiry day, day 30, day 31, yesterday, year changes, and leap day. |
| Shared mutable batch log | Tool: Pylint W0102 | 24 | Calls share the default list, so independent additions accumulate an unrelated batch count. | Default to `None` and allocate a list per call; retain explicitly supplied logs and test both cases. |
| Bare exception handling | Tool: Pylint W0702; Flake8 E722 | 38, 58 | The code hides programming errors and catches control-flow exceptions. The dispensing block masks missing patient/stock cases. | Use explicit dispensing guards; handle only a missing stock file as optional. Propagate malformed JSON, invalid data, and permission errors. |
| Silently ignored loading errors | Tool: Bandit B110, low severity, high confidence | 58-59 | `except: pass` suppresses every stock-loading failure without telling the caller. | Return `False` for `FileNotFoundError` only, return `True` for successful loads, and test that other failures remain visible. |
| Unsafe/unencoded file handling | Tool: Pylint R1732, W1514 | 50, 57 | Export may leave a file open after an exception; load opens a file without reliably closing it. Encoding is platform dependent. | Use context managers with explicit UTF-8; test round-trip JSON and context exit on serialization failure. |
| Inconsistent stock keys | Manual: correctness | 25, 35, 70-75 | Stock uses title-case names while dispensing may receive lowercase; this causes a valid stock lookup to fail. | Apply the same medicine normalization to additions, dispensing, and loading. Merge loaded equivalent names only when their expiry dates agree. |
| Unvalidated loaded stock and overwritten expiry | Manual: correctness | 25, 55-57 | Loading accepts arbitrary JSON shapes and invalid units/dates. Adding a different expiry replaces the date on existing units, potentially masking expired stock. | Validate the entire inventory before updating the existing dictionary; reject conflicting dates. Permit a new expiry only when no old units remain. Test atomic rejection. |
| Global dictionary replacement | Tool: Pylint W0603; manual state concern | 55, 57 | The global assignment discards existing dictionary references and installs unvalidated input. | Validate in a temporary dictionary, then clear/update the existing stock mapping. |
| Missing documentation and inconsistent naming | Tool: Pylint C0114, C0116, C0103 | 1; 11, 19, 24, 29, 41, 49, 54, 61, 66 | Module/functions lack contracts, and `printStock` violates snake_case naming. | Document behavior and failure contracts; rename to `print_stock` and update the call site. |
| Unused import | Tool: Pylint W0611; Flake8 F401 | 3 | `os` is unused. | Remove the import. |
| Formatting | Tool: Pylint C0301; Flake8 E501, E302, E305 | 36 (Pylint); 25, 36 (E501); 11, 19, 24, 29, 41, 49, 54, 61, 66 (E302); 83 (E305) | Long lines and insufficient spacing around top-level functions violate the tools' default style checks. | Wrap expressions to 79 columns and use two blank lines between top-level definitions and before the main guard. |
| Interactive execution during import | Manual: testability/resource handling | 83 | Importing immediately creates data, asks for input, and writes a prescription file, preventing isolated tests. | Add a main guard; close the SQLite connection when the command-line program finishes. Keep sample database setup repeatable. |

The baseline contains 22 Pylint messages (score 6.90/10), two Bandit findings
(one medium and one low), and 15 Flake8 findings. No warnings are suppressed.
See `reports/after/` and the README validation summary for final measured results.
